# Bomberman-CE

A Python-based Bomberman game clone created with Pygame. This project features classic Bomberman gameplay with modern twists, custom graphics, and audio.

## 🎮 Game Overview

Bomberman-CE is a 2D maze-based action game where the player must navigate through a level, avoid enemies, and place bombs to clear barriers. The ultimate goal is to find the key, unlock the door, and proceed to the next level.

## 🎯 Gameplay Mechanics

- **Goal**: Find the key, unlock the door, and advance to the next level
- **Bombs**: Place bombs to destroy barriers and defeat enemies
- **Enemies**: 
  - **Scouts**: Move in straight lines until they hit an obstacle
  - **Conjurers**: More advanced enemies with unpredictable movement patterns
- **Lives System**: You have a limited number of lives to complete the game

## 🎹 Controls

- **W**: Move up
- **A**: Move left
- **S**: Move down
- **D**: Move right
- **Space**: Place bombs

## 🛠️ Technologies

- **Python**: Core programming language
- **Pygame**: Game development library for Python
- **Custom Game Engine**: Built from scratch with functional programming patterns

## 💻 Installation

1. Ensure you have Python installed (Python 3.6 or higher recommended)
2. Install Pygame:
```bash
pip install pygame
```
3. Clone the repository:
```bash
git clone https://github.com/TheDeGeO/Bomberman-CE.git
```
4. Navigate to the project directory:
```bash
cd Bomberman-CE
```
5. Run the game:
```bash
python bomberman.py
```
